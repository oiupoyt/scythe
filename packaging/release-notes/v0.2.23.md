### Fixed
- Recordings started after the daemon had been idle froze on their first frame for about as long as it had idled. They now start on the frame you asked for.
- The last moments of audio in a recording were dropped, by up to 1.5 s. Instant replay could keep as little as 4 s of audio in a 15 s clip. Both now keep all captured audio.
- Stopping the daemon, logging out or `systemctl --user stop` left an unplayable file when a recording was running. The recording is now finalized first.
- A settings change killed a daemon started from Hyprland `exec` or XDG autostart. It now restarts itself.
- Every launch restarted `xdg-desktop-portal`, interrupting screen sharing in other apps. It no longer does.
- Saving settings could leave `config.json` truncated or overwrite it with defaults. Saves are now atomic, and the file is readable only by you.
- Back, Escape or clicking outside Settings silently threw away your changes. Every way out now applies them.
- Browse in the Screenshot tab changed the recordings folder.
- `scythe --cursor` reported a change that recordings never picked up.
- Instant replay emptied itself on a settings change in low-power mode, and held only about two thirds of the configured length.
- Stopping the daemon left four hotkeys bound, and pressing the pause key started it again.
- X11 capture leaked a screen-sized shared memory block readable by any user on every run.

### Faster
- The overlay redraws only when something changes: idle CPU fell from 3.6% to under 1%.
- Settings changes no longer pause an active recording, and Save & Close no longer freezes the overlay.

### Safer
- Updates are checked against the `SHA256SUMS` file published with each release, and refused on a mismatch. The tarball update now replaces the actual binary; before, it reported success and changed nothing.
- Hotkeys must use Ctrl, Alt or Shift (F-keys still work alone), so a stray letter can no longer become a global shortcut.
- The daemon rejects oversized IPC messages instead of allocating them.

Updating from 0.2.22 or earlier: those releases have no checksums, so their in-app updater cannot verify this one and will decline it. Install 0.2.23 manually once; later updates verify themselves.
