High-performance GPU hardware screen recorder and instant replay overlay for Linux and Windows.

### Packages
- **Windows**: `scythe-setup.exe` (Official installer with Start Menu & Desktop shortcuts)
- **Windows Portable**: `scythe.exe` (Standalone portable launcher)
- **Windows Archive**: `scythe-windows-x86_64.zip` (Portable zip archive)
- **Universal Linux**: `scythe-x86_64.AppImage`
- **Debian / Ubuntu / Mint**: `scythe_*_amd64.deb`
- **Fedora / RHEL / openSUSE**: `*.rpm`
- **Generic Linux**: `scythe-linux-x86_64.tar.gz`
- **Checksums**: `SHA256SUMS` (SHA-256 of every file above; the in-app updater checks it)
